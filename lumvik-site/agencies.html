ProcessBrief to handover

The same five steps, every project.

  1. Brief

    Send the design file, copy and any must-haves. Figma, a PDF or a rough sketch all work.

  2. Quote

    Scope, price and a delivery date agreed in writing before any work starts.

  3. Build

    Built in Next.js or clean HTML, with progress on a private preview link.

  4. Review

    You check it on desktop and phone. Two rounds of changes are included.

  5. Handover

    Deployed to your hosting or handed over as code. Yours, unbranded.

QualityIn every build

What every build includes.

Responsive

Layouts checked at phone, tablet and desktop widths, with no sideways scrolling and tap targets sized for thumbs.

Fast

Compressed images, minimal scripts and no heavy page builders. We check page speed before you see the first preview.

Accessible

Semantic markup, visible keyboard focus, readable contrast and form errors that screen readers announce.

Search-ready

Unique page titles and descriptions, a sitemap, robots.txt, social preview images and redirects for any changed URLs.

Forms that work

Every form is submitted and checked end to end, so enquiries reach the right inbox or CRM from launch day.

Clean handover

Readable code in your repository, deployed to your hosting, with a short note on how to make common edits.

QuestionsPartnership

Partnership questions.

Can we start with a small test project?

Yes, and we recommend it. Send one landing page; if the quality and communication work for you, we take it from there.

What do you need from us to start?

A design file or reference, the copy, any brand assets, and where the site should live. If something's missing, we'll say what in the quote.

Which tools and platforms do you build with?

Mostly Next.js, React and Tailwind, deployed on Vercel. We can also deliver clean static HTML. We don't currently build on WordPress or Shopify.

How are changes handled?

Two review rounds are included in every quote. New features beyond the agreed scope are quoted separately before we start them.

How do we pay?

By international bank transfer or PayPal, invoiced in US dollars. 50% upfront and 50% on handover.
